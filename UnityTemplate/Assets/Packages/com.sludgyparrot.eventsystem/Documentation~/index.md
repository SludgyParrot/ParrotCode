# Event System Package

Install the parrot code event system, which allows you to publish and recieve runtime events using an **EventBus**. To install the package, add it to the Unity Package Manager registy using the Parrot Code npm package url and [install it from the registry](xref:upm-eventsystem-install). If you already have the **Parrot Code** [input system](xref:) installed in your project, this package is automatically installed.

This version of event system is compatible with the following versions of the Unity editor:

* 2019 LTS and later (recommended)
