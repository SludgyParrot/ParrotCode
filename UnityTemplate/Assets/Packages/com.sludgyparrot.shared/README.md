# Parrot Code Shared Editor Utilities

A collection of shared editor utilities, inspector tooling, property drawers, validation systems, and reusable editor components used throughout the Parrot Code ecosystem.

## Features

* Custom inspector helpers
* Property drawer utilities
* Validation systems
* Editor UI components
* Shared editor workflows

## Installation

Install via the Unity Package Manager.

## Dependencies

* Parrot Code Native
* Parrot Code Extensions

## Usage

This package is intended for editor-only tooling and serves as a dependency for other Parrot Code editor packages.

Example features include:

* Custom inspectors
* Editor validation
* SerializedProperty helpers
* Editor GUI utilities

## Compatibility

* Unity 2022.3 LTS or newer
