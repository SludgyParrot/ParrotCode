# Parrot Code VR

A collection of virtual reality utilities, XR Interaction Toolkit extensions, and development tools for building immersive VR experiences in Unity.

## Features

* 🥽 XR Interaction Toolkit extensions
* 🕹️ VR interaction helpers
* 🚶 Locomotion systems
* ✋ Hand and controller interaction utilities
* 🎯 Object grabbing and manipulation
* 📍 Teleportation helpers
* 🎮 Cross-platform XR input abstraction
* 📊 VR performance optimization helpers
* 🧩 OpenXR integration utilities
* ⚙️ VR project configuration helpers

## Installation

Install the package via the Unity Package Manager.

### Dependencies

* Parrot Code Native
* Parrot Code Extensions
* Unity XR Plug-in Management
* Unity XR Interaction Toolkit

These dependencies will be resolved automatically by the Unity Package Manager.

## Usage

Import the required namespace into your scripts:

```csharp
using ParrotCode.VR;
```

The package extends Unity's XR Interaction Toolkit with reusable components, utilities, and high-level APIs for creating immersive virtual reality applications.
