# Parrot Code Audio

A collection of audio managers, playback systems, mixers, utilities, and development tools for building rich audio experiences in Unity applications.

## Features

* 🎵 Audio manager framework
* 🔊 Sound effects playback
* 🎼 Music playback and playlists
* 🎚️ Audio mixer utilities
* 🔁 Audio pooling
* 🎧 2D and 3D audio helpers
* 🔉 Volume management
* 🎲 Randomized sound playback
* 🎛️ Audio fading and crossfading
* 🎹 Runtime audio configuration

## Installation

Install the package via the Unity Package Manager.

### Dependencies

* Parrot Code Native
* Parrot Code Extensions

These dependencies will be resolved automatically by the Unity Package Manager.

## Usage

Import the required namespace into your scripts:

```csharp
using ParrotCode.Audio;
```

The package provides reusable audio systems for managing music, sound effects, audio sources, and playback behaviours across Unity projects.
