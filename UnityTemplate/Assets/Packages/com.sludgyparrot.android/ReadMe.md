# Parrot Code Android

A collection of Android utilities, native Java plugins, Gradle configuration tools, and runtime APIs for developing Unity Android applications.

## Features

* 📷 Runtime Android camera access helpers
* 📁 File import and export utilities
* 📤 Native file sharing via Android intents
* 🔐 Android runtime permission management
* ⚙️ Gradle build configuration helpers
* 🧩 Native Java plugin bridge utilities
* 📦 Android build customization
* 📱 Device and system information APIs
* 📂 Storage access framework helpers
* 🔔 Android intent utilities

## Installation

Install the package via the Unity Package Manager.

### Dependencies

* Parrot Code Native
* Parrot Code Extensions

These dependencies will be resolved automatically by the Unity Package Manager.

## Usage

Import the required namespace into your scripts:

```csharp
using ParrotCode.Android;
```

The package provides high-level C# APIs that wrap native Android functionality, reducing the need to write or maintain custom Java plugins.
