# Parrot Code AR

A collection of augmented reality utilities, AR Foundation extensions, and development tools for building immersive AR and mixed reality applications.

## Features

* 🥽 AR Foundation utilities
* 📍 Plane detection helpers
* 🖼️ Image tracking utilities
* 📦 Object placement and manipulation
* 🧭 Spatial anchoring helpers
* ✋ Gesture interaction utilities
* 📷 Camera and environment helpers
* 🧠 AI-assisted AR workflows
* 🌍 World-space utility components
* ⚙️ Cross-platform AR abstractions

## Installation

Install the package via the Unity Package Manager.

### Dependencies

* Parrot Code Native
* Parrot Code Extensions
* Parrot Code AI

These dependencies will be resolved automatically by the Unity Package Manager.

## Usage

Import the required namespace into your scripts:

```csharp
using ParrotCode.AR;
```

The package extends Unity's AR Foundation framework with reusable components, utilities, and higher-level APIs for building augmented reality applications.
